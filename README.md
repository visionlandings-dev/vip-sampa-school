# Sampa School Connect

Precisa incluir os logotipos da sampa.school e sampa.group integrados no cabeçalho e botões de ação variados (CTAs) espalhados por cada seção do site para garantir que o visitante clique e vá para o seu WhatsApp a qualquer momento. É importante que todas as páginas apresentem os botões de set up. Na verdade a primeira landing page da sampa.school é bastante simples e de fácil leitura para venda das primeiras turmas que começam em 26 e 27 de agosto. A matrícula é de 70,00 e a mensalidade é de 180,00. Tenho certeza que já teremos algum faturamento em agosto com a sampa.school. 

No total são 5 sessões de landing page além do rodapé. Abaixo está completo, agora é só colocar no seu carrossel de engrenagem e fazer rodar!
